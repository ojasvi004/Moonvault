## Why 0G?

Moonvault is a **private period tracker** — every AI interaction touches deeply personal health data. 0G Private Computer gives us verifiable, zero-retention inference so users get intelligent features **without surrendering their data to a model provider**.

Every AI response ships with a **0G Verification ID** (request receipt) that proves the computation happened on 0G infrastructure — auditable, transparent, no trust required.

## How Moonvault Uses 0G

### 🎙️ Voice Health Logging (0G Private Computer)

Users speak up to 45 seconds of audio describing their day — flow intensity, symptoms, mood, sleep. The audio is transcribed and parsed into structured medical fields entirely via 0G PC.

| Step | Model | Endpoint |
|------|-------|----------|
| Speech → Text | `openai/whisper-large-v3` | `/audio/transcriptions` |
| Fallback STT | `qwen3.5-omni-flash` | `/chat/completions` (audio-capable) |
| Text → Structured JSON | `qwen3.7-flash` | `/chat/completions` |

**Privacy guarantee:** Raw audio never leaves the request. The structured JSON is encrypted client-side (XChaCha20-Poly1305) before storage.

### 💬 "Ask Your Cycle" Assistant (0G Private Computer)

Users ask natural-language questions about their cycle patterns ("Why am I so tired this week?", "When is my next period likely?"). Before any data reaches 0G:

1. **Anonymization** — Names, emails, phone numbers, @handles, and titled names (Dr./Mr.) are scrubbed via regex ([`lib/ai/anonymize.ts`](../lib/ai/anonymize.ts))
2. **Date relativization** — All dates are converted to `daysAgo` offsets (never absolute dates)
3. **Relevance filtering** — Only entries matching the question's time window are included
4. **Size cap** — Input truncated to 64 KB max

The response includes the **0G Verification ID** — a receipt proving the query was processed on 0G infrastructure with zero data retention.

### 📊 Trend & Pattern Analysis (0G Private Computer)

Multi-month cycle logs are synthesized into actionable hormonal phase insights:

- **Insights task** — Pattern analysis across all logged cycles
- **Day task** — Single-day deep analysis
- **Summary task** — Doctor-ready summary formatted for clinical handoff

All use `qwen3.7-flash` at temperature 0.4 (0 for structured output), with the same anonymization pipeline.

### 🔊 Text-to-Speech Read-Aloud (0G Private Computer)

AI-generated insights can be read aloud using 0G's TTS endpoint:

| Model | Voice | Endpoint |
|-------|-------|----------|
| `minimax-speech-2.8-turbo` | `alloy` | `/audio/speech` |

### 💾 Encrypted Backup Storage (0G Storage)

Moonvault uses 0G's decentralized storage network for encrypted backup bundles:

1. Client seals all entries + AI results into a bundle: `"MVB" 0x01 ‖ seal(DK, gzip(JSON), "moonvault:backup:v1")`
2. Server uploads the **ciphertext** (never plaintext) via `@0gfoundation/0g-ts-sdk`
3. Returns a **Merkle root** hash as the content address
4. Root is saved to the user's Arkiv profile record for cross-device restore

```
Client (browser)                     Server                         0G Storage
  │                                    │                                │
  │── encrypt(DK, bundle) ────────────►│                                │
  │                                    │── zgUpload(ciphertext) ───────►│
  │                                    │◄── { root, txHash } ──────────│
  │◄── { root, anchored } ────────────│                                │
  │                                    │                                │
  │── GET /download?root=... ─────────►│                                │
  │                                    │── zgDownload(root) ───────────►│
  │                                    │◄── ciphertext ────────────────│
  │◄── octet-stream ──────────────────│                                │
  │── decrypt(DK, ciphertext) ────────►(local)                         │
```

**Key design:** The server only ever handles ciphertext. Decryption keys exist exclusively in the browser's memory.

## Verification ID — Auditable AI

Every 0G PC response returns a verification receipt:

```json
{
  "text": "Based on your last 3 cycles...",
  "requestId": "0g-abc123def456",
  "model": "qwen3.7-flash"
}
```

The `requestId` is extracted from `x_0g_trace.request_id` in the response body, proving the computation was processed by 0G's verifiable inference network. Users see this ID alongside every AI answer in the UI.
